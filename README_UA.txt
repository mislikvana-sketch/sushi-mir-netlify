SUSHI MIR — сайт меню та замовлень для Netlify

ЩО Є:
- Адаптивний сайт українською, меню, категорії та кошик.
- Форма замовлення: ім'я, телефон, Telegram (необов'язково), «з собою / у закладі», коментар.
- Netlify Function надсилає замовлення в Telegram.
- Адмін-панель без пароля: додавання товару з фото, назвою, описом, ціною та вагою; видалення товарів.

ВАЖЛИВО ПРО АДМІНКУ:
За вашим проханням вона без пароля. Це означає, що будь-хто, хто відкриє сайт, може відкрити її та видаляти/додавати товари. Також каталог зберігається в localStorage лише в браузері адміністратора: зміни не синхронізуються між відвідувачами та пристроями. Для справжнього публічного магазину потрібна база даних і захищений вхід. Не зберігайте тут конфіденційні дані.

ЯК ОПУБЛІКУВАТИ БЕЗКОШТОВНО:
1. Розпакуйте архів.
2. Створіть репозиторій на GitHub і завантажте ВСІ файли та папку netlify.
3. На netlify.com увійдіть через GitHub → Add new site → Import an existing project → виберіть репозиторій.
4. Build command залиште порожнім, Publish directory — ".". Netlify підхопить netlify.toml.
5. Після деплою відкрийте Site configuration → Environment variables і додайте:
   TELEGRAM_BOT_TOKEN = токен від @BotFather
   TELEGRAM_CHAT_ID = ваш chat ID
6. Зробіть redeploy сайту.

ЯК СТВОРИТИ TELEGRAM-БОТА:
1. У Telegram знайдіть @BotFather.
2. Надішліть /newbot, задайте назву SUSHI MIR Orders і username, який закінчується на bot.
3. Скопіюйте токен. НІКОМУ його не надсилайте та не вставляйте у frontend-код.
4. Відкрийте створеного бота та натисніть Start.
5. Щоб отримати chat ID: напишіть боту будь-яке повідомлення, потім відкрийте в браузері:
   https://api.telegram.org/botВАШ_ТОКЕН/getUpdates
   Знайдіть "chat":{"id": ЧИСЛО ...}. Це і є TELEGRAM_CHAT_ID.
   Якщо бот у групі: додайте його в групу, надішліть повідомлення в групу й перевірте getUpdates; для групового ID часто буде від'ємне число.
6. Додайте обидві змінні в Netlify, виконайте redeploy і протестуйте замовлення.

ЗМІНИ:
- Телефон, адреса/посилання Telegram і тексти сайту можна змінити в index.html.
- Початкові товари та фото — у масиві defaultProducts у app.js.
- Стилі — style.css.
- Telegram-функція — netlify/functions/order.js.

ПРИМІТКА:
Netlify Functions і статичний хостинг мають безкоштовні ліміти, які можуть змінюватися. Перевіряйте актуальні умови Netlify. Замовлення надсилаються у Telegram; база замовлень на сайті не ведеться.
